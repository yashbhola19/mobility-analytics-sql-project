# Mobility Analytics SQL Project

## Project Overview

Mobility Analytics is a SQL based data analytics project created using MySQL.

The project analyzes data from a mobility platform including users, drivers, rides, vehicles, payments, ratings, cities and promotions.

The project contains 30 SQL queries divided into Easy, Moderate and Advanced levels.

## Project Objectives

Analyze user activity

Analyze driver performance

Analyze ride behavior

Analyze revenue generation

Analyze vehicle performance

Analyze payment methods

Analyze ratings and feedback

Analyze promotional campaigns

Generate business insights using SQL
